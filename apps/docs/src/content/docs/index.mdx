## Architectural Advantages

<CardGrid stagger>
  <Card title="Multi-Ecosystem Integration" icon="magnifier">
    Query and deploy modpacks, mods, shaders, and resource packs across both Modrinth and CurseForge simultaneously within a unified interface.
  </Card>
  <Card title="Normalized Download Ranking" icon="star">
    Results are automatically sorted by total download count descending (`20M+ → 3M+ → 100K+`), ensuring industry-standard packs rise to the top.
  </Card>
  <Card title="Zero Ad & Telemetry Commitment" icon="approve-check-circle">
    Engineered without advertising frameworks, sponsored placements, or third-party tracking analytics.
  </Card>
  <Card title="Automated Java Bootstrapping" icon="setting">
    Automatically detects, downloads, and configures the exact Eclipse Temurin Java runtime (Java 8, 17, or 21) mandated by each Minecraft instance.
  </Card>
  <Card title="Automated Crash Diagnostics" icon="warning">
    Parses logs and crash reports locally in Rust to instantly diagnose missing library dependencies, duplicate mod IDs, and bytecode conflicts.
  </Card>
  <Card title="Native Systems Performance" icon="rocket">
    Built on a native **Rust and Tauri 2.0** core with a responsive **Vue 3 and TypeScript** user interface for Linux, Windows, and macOS.
  </Card>
</CardGrid>
